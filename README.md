# CTF Notes

A practical, evidence-first collection of TryHackMe and authorized pentesting notes.

## Contents

- `skills/ctf-solver/SKILL.md`: reusable collaboration workflow and CTF solving playbook
- `writeups/`: room write-ups and command references
- `Attackative Directory/`: the original local Attacktive Directory session materials

## Safety

Raw username/password lists, captured hashes, and local credential artifacts are excluded from version control. The write-ups document the methods and verified answers without publishing reusable lab secrets.

Use these techniques only against systems and labs you are authorized to test.
